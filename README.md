# inDrive hero slogan builder

Одностраничный конструктор hero-слоганов inDrive: набираешь текст, подбираешь раскладку и выгружаешь готовую картинку через html2canvas.

## Запуск

Статическая страница без сборки — достаточно открыть `index.html` в браузере или поднять любой локальный сервер:

```bash
python3 -m http.server 8000
```

## Шрифты

PP Agrandir и Suisse Intl — коммерческие шрифты, поэтому в репозитории они не хранятся. `index.html` подключает их напрямую с CDN inDrive (`indstatic.io`, отдаётся с `Access-Control-Allow-Origin: *`). Если файлы там переедут, шрифты откатятся на системные — нужно будет обновить URL в блоках `@font-face`.
